# abbott dance

1. install bun
2. run `bun install`
3. run `cp .env.example .env`
4. find abbott's ip + flask port (should be :5000) and fill it in
5. make sure abbott is running the direct control flask app (not in this repo, see https://github.com/jm771/AbbottTheOctopus/blob/main/direct_control_main.py)
6. run `bun run dev`
7. dance!
